Events, functions, structures and data tables added by the MMMerge scripts and the Waffel Edition on top of MMExtension v2.3. Keep this page next to MMExtension.htm: links to the base structures and constants point into it.

Events are handled the usual way, function events.Name(t) ... end. Fields marked as results (Result, Handled and so on) may be changed by the handler. Merge.Functions is usually aliased as local MF = Merge.Functions in the scripts. Structures list the game memory MMMerge adds or enlarges and the plain Lua tables it keeps on Game; Data Tables describe the files in Data\Tables and the scripts that read them.
