Merge / Waffel Edition API

Events and functions added by the MMMerge scripts and the Waffel Edition on top of MMExtension v2.3. Keep this page next to MMExtension.htm: links to the base structures and constants point into it.

Events are handled the usual way, function events.Name(t) ... end. Fields marked as results (Result, Handled and so on) may be changed by the handler. Merge.Functions is usually aliased as local MF = Merge.Functions in the scripts.

{

}		Called once when the game date changes to a new day. NewWeek, NewMonth and NewYear are called before it with the same table, and set NewWeek, NewMonth, NewYear to true when they happened, so a NewDay handler can tell what else changed.
DayOfMonth, Month, Week, DayOfWeek start from 0. Year is the calendar year, GameYear the years since the start of the game. GameDay and PrevGameDay count days since the start (GetGameDay: 28 days a month, 12 months a year); the difference shows how many days passed at once. Prev* are the date before the change.
Type: 1 = the game clock, 2 = a jump in time (travel, rest, training and the like), 3 = a jump while walking to another map: delayed until the new map is loaded, 4 = a new game (called on the first map load with day 0).
Example:
function events.NewDay(t)
if t.NewWeek then
Game.ShowStatusText("A new week begins")
end
local passed = t.GameDay - (t.PrevGameDay or t.GameDay) -- several days at once after travel
end

}		Called for every shop and temple price, after the Waffel Edition formula and the multipliers of Economy.Settings; change Result to set the price (it is clamped to Economy.Settings.MinPrice afterwards).
Kind: "Heal", "Sell", "Buy", "Identify", "Repair", the merchant-skill-free "BaseSell", "BaseBuy", "BaseIdentify", "BaseRepair" (shown by the merchant), or "DarkHeal" (the reanimation price of dark temples, ZombiePlayers.lua).

Example:
-- temples heal for half the price
function events.CalcEconomyPrice(t)
if t.Kind == "Heal" then t.Result = math.ceil(t.Result / 2) end
end
